#  Interactive Customer Churn Analytics Dashboard

An interactive Customer Churn Analytics Dashboard developed using Python and data visualization techniques to analyze telecom customer churn, identify churn patterns, and generate meaningful business insights.

---

##  Project Overview

Customer churn is an important business problem in the telecom industry. Losing customers can significantly affect revenue and business growth.

This project analyzes telecom customer data to understand:

- Which customers are more likely to churn
- Factors associated with customer churn
- Customer demographics and service usage
- Contract and tenure patterns
- Monthly charges and their relationship with churn

The analysis is presented through interactive data visualizations in a Jupyter Notebook.

---

##  Objectives

The main objectives of this project are:

- Analyze customer churn behavior
- Identify important factors affecting churn
- Explore customer demographics
- Analyze contract types and tenure
- Study monthly charges and customer churn
- Create meaningful visualizations
- Generate insights that can help improve customer retention

---

##  Technologies Used

- Seaborn
